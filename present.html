PREDICTIVE CLASSIFICATION

Decision-tree model: next step

A decision tree could use session attributes such as visitor type, page activity, bounce rate, exit rate, and page values to classify the Revenue outcome. The current website presents descriptive analysis; it does not yet run a trained predictive model.

To report a valid model result, the project still needs a documented train/test split, model training, and evaluation using a confusion matrix, accuracy, precision, recall, and F1-score. No predictive accuracy is claimed on this page.

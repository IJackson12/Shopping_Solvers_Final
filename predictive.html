How the experiment works

  1. Load the 12,330-row UCI CSV already stored in this repository.
  2. Separate the target, Revenue, from the input features.
  3. Split the data into training and testing sets using a fixed seed and stratification, preserving the purchase/no-purchase proportions.
  4. Train a shallow CART-style decision tree using weighted Gini impurity to account for the smaller purchase class.
  5. Evaluate both models on the same held-out test sessions.

The tree is intentionally kept shallow and uses a minimum leaf size to reduce overfitting and keep the rules readable. Results are reproducible in the browser from the repository's CSV; no predictive score is hard-coded.

DATA AND RESEARCH SOURCES

What these fields can tell us

Visitor type: distinguishes new, returning, and other visitors. It gives context about the visitor category, but does not determine purchase intent by itself.

Page activity: counts and duration for administrative, informational, and product-related pages can represent how visitors explore a site.

Bounce and exit rates: describe session/page behavior and can help distinguish sessions with limited interaction from sessions with more navigation.

PageValues: a transaction-associated field in the UCI dataset. It can be informative retrospectively, but should be treated cautiously for early prediction because it may be closely tied to the purchase outcome.

Primary dataset: Sakar, C., & Kastro, Y. (2018). Online shoppers purchasing intention dataset. UCI Machine Learning Repository. https://doi.org/10.24432/C5F88Q. Dataset documentation: UCI dataset page.

Related peer-reviewed research: Sakar, C. O., Polat, S., Katircioglu, M., & Kastro, Y. (2019). Real-time prediction of online shoppers’ purchasing intention using multilayer perceptron and LSTM recurrent neural networks. Neural Computing and Applications, 31, 6893–6908. Read the research paper. The paper provides research context for using aggregated pageview behavior and session information to study purchasing intention.

Research note: this page uses the UCI dataset as the source of both predictors and Revenue labels. External research is used to explain the behavioral context, not to create extra labeled records or inflate the model's sample size.

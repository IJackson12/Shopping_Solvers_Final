PRIMARY DATASET

UCI Online Shoppers Purchasing Intention

12,330 online shopping sessions with visitor, page activity, timing, and Revenue outcome attributes. This is the primary dataset used for the calculated charts in Shopping Solvers.

Open UCI Dataset ↗
EVENT DATA REFERENCE

Google Analytics Ecommerce Demo

A BigQuery sample dataset that demonstrates ecommerce event data and the customer journey. It provides a reference for event-based analytics; it is not merged into the UCI session totals.

Open Google Resource ↗
EXTERNAL RESEARCH

Baymard Checkout Usability

Research about checkout usability and reasons shoppers abandon carts. These findings provide context and should be kept separate from the UCI dataset's no-purchase sessions.

WHAT THE UCI DATA CONTAINS

Session attributes

Attribute groupExamplesHow it is used
Visitor informationVisitorType, WeekendCompare new and returning visitors, and weekdays vs. weekends.
Page activityAdministrative, Informational, ProductRelatedMeasure browsing activity during a session.
Time and engagementPage durations, Month, SpecialDayExplore timing and time spent on pages.
Session behaviorBounceRates, ExitRates, PageValuesCompare engagement and session characteristics.
Outcome labelRevenueIdentify whether the session resulted in a purchase.
Important limitation: Revenue = False means the session did not result in a purchase. It does not prove that the shopper added an item to a cart and abandoned it.
